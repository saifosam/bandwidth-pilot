# Changelog

## 0.3.0 - 2026-11-12

### Added
- Notification area icon. Closing the window keeps your limits running; the
  tooltip shows live speeds; right-click to pause all rules or quit.
- Start with Windows, through a Task Scheduler entry so it starts elevated
  without a permission prompt.
- Schedules: any rule can apply only on chosen days and times, including
  overnight windows.
- Per-process rules: show an app such as Chrome as one row per process and
  limit just one of them.
- Connections tab: a log of every new connection with the website name,
  port and whether it was allowed or blocked.
- Websites tab: block or limit a site, IP address or range for every app at
  once, with presets for YouTube, Netflix, TikTok, Instagram and Facebook,
  Twitch, Steam downloads and Windows Update.
- Optional prompt before apps you have never used go online.
- Windows installer with Start menu shortcut, uninstaller and an option to
  start with Windows.

### Changed
- Opening the app while it is already running brings the window to the front.

## 0.2.0

- New name and logo: Bandwidth Pilot.
- Activity list grouped like Task Manager: Apps, Background processes and
  Windows processes.

## 0.1.0

- First version: live per-app speeds and connections, speed limits, blocking,
  priorities inside a total bandwidth cap, daily quotas and 30-day usage history.
